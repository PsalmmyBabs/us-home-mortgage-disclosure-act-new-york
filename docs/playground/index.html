US HMDA 2022 to 2025 · SQL Playground

1,754,846 mortgage applications from New York State, in fifteen tables, running in your browser. Nothing is installed and nothing is sent to a server.

Starting the database engine…

Edit anything here and press Ctrl + Enter to run it. Your changes live in this browser tab only. Picking another query from the list, or reloading the page, brings the original back.

The engine is DuckDB compiled to WebAssembly, served from this site rather than a CDN. The data is 82 MB of Parquet in nineteen files, one per table and one per year of the fact table. Where the host supports HTTP range requests, as GitHub Pages does, a query that touches one year fetches roughly that year's bytes rather than the whole dataset.

Schema and view names match the PostgreSQL build exactly, so every query here is the query in docs/08_analysis.md, unedited. A parity test in the repository runs all ten against both engines and fails on any difference.
